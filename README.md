# Video-Rytme

## Rhythm Flow

Entraîneur visuel de rythme et de profondeur pour adultes.

### Fonctionnalités

- Visualisation immersive de la position et de la profondeur
- Zones cibles configurables
- Modes : Régulier, Aléatoire, Stop & Go, Progressif, Endurance et Rythme
- Séances rapides : Douceur, Débutant, Rythme, Intense et Aléatoire
- Minuteur et barre de progression
- Statistiques de fin de séance
- Vitesse, pauses, variation et BPM configurables
- Orientation verticale ou horizontale
- Sauvegarde locale des réglages
- Vibrations optionnelles lorsque le navigateur le permet
- Prise en charge de la réduction des animations
- Interface responsive pour mobile
- Raccourcis : Espace pour démarrer/mettre en pause, R pour réinitialiser

## Lancer le projet

Ouvrir `index.html` dans un navigateur ou activer GitHub Pages pour héberger le site.

## Structure

- `index.html` : interface
- `style.css` : design responsive et animations
- `script.js` : moteur de mouvement, modes, minuteur et statistiques
