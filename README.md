# Video-Rytme

## Rhythm Flow

Indicateur visuel de rythme : un point monte et descend sur une barre verticale avec une vitesse variable et des pauses imprévisibles.

### Fonctions
- vitesse variable
- pauses aléatoires en haut, en bas ou à une position quelconque
- durée de pause réglable
- chance de pause réglable
- interface responsive pour mobile
- aucun serveur nécessaire

Ouvrir `index.html` pour tester le site.
